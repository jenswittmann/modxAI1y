## ContentBlocks-Image-ALT-Text-Generator

ContentBlocks-Image-ALT-Text-Generator creates alt texts for images in ContentBlocks with Claude or InkluDocs. A button next to the title field of an image
describes the image on click. The API key stays on the server.

Choose the service in `cbaltgenerator.provider` and set its API key (`cbaltgenerator.apikey` or `cbaltgenerator.inkludocs_apikey`) before the first use.
