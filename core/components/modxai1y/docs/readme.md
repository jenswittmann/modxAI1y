## modxAI1y

modxAI1y creates alt texts for images in ContentBlocks with Claude or InkluDocs. A button next to the title field of an image
describes the image on click. The API key stays on the server.

Choose the service in `modxai1y.provider` and set its API key (`modxai1y.apikey` or `modxai1y.inkludocs_apikey`) before the first use.
